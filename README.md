# Kaden Digital

Website of Kaden Digital, Ljubljana. Web development, mobile apps and automation.

**Live:** [www.kaden-digital.com](https://www.kaden-digital.com)

## Built with

Plain HTML, CSS and JavaScript. No frameworks, no build step, no dependencies.
Hosted on GitHub Pages.

## Notes

* Fonts are served from this repository, so no visitor data leaves to a third party
* Icons are local SVG files for the same reason
* Images below the fold load only when the visitor scrolls to them
* 3D and scroll effects run on CSS scroll driven animations, without JavaScript
